# やる事カレンダー

日付ごとに「やる事」と「予定（スケジュール）」を管理できる、ブラウザで動くアプリです。
以前の「やる事リスト」にカレンダー機能を加えたものです。

## できること

- 月のカレンダーで日付を選ぶ（予定がある日は ● 、未完了のやる事がある日は ○ が付きます）
- 選んだ日に「やる事」または「予定（開始・終了時刻つき、空欄なら終日）」を追加する
- 予定には場所とメモ（複数行）を書け、あとから「編集」で直せる
- 予定は開始日と終了日を選べ、日付をまたぐ予定（出張・旅行など）は期間中の毎日に表示される
- やる事は丸をタップして完了・未完了を切り替え、「翌日へ」で次の日に回す
- 今日を開くと、前の日までに終わらなかったやる事が「持ち越し」として表示される
- × で削除、「この日の完了したものを削除」でまとめて削除

## 2つの使い方

### 1. claude.ai 版（おすすめ）

https://claude.ai/artifact/4yx2x4DMLfYEiPpJwj8LnV

データは claude.ai 上に保存されるので、スマホとパソコンなど別の端末でも同じ内容が見られます。
毎朝のモーニングブリーフがここを読み込み、「今日のやる事と予定」として表示します。
（自分だけが開けるページです）

### 2. このリポジトリの `index.html`

ブラウザで開くだけで使えます。データはその端末のブラウザにだけ保存され、モーニングブリーフからは読めません。
以前の「やる事リスト」のデータがあれば、最初に開いたときに今日のやる事として引き継ぎます。

## claude.ai 版を更新するとき

`index.html` を直したら、公開用のファイルを作ってから claude.ai に公開し直します。

```
python3 tools/build-artifact.py planner.html
```

## iPhone のホーム画面に置く

claude.ai のページをそのままホーム画面に追加すると、アイコンは Claude のものになります。
黒いカレンダーのアイコンで置きたいときは、入口ページ `open.html` を使います（このリポジトリを GitHub Pages で公開している場合）。

1. Safari で `https://<ユーザー名>.github.io/my-project/open.html#setup` を開く
2. 共有ボタン →「ホーム画面に追加」（「Webアプリとして開く」はオフ）
3. 追加したアイコンを開くと、claude.ai のやる事カレンダーへ移動します
